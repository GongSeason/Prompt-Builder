# 2026-11-23 需求补充裁决：V1.4.1

## 决策背景

用户希望网页生成的提示词告诉模型应把各阶段文档写到什么路径。V1.4 加入落盘规则后，Sonnet P3 指出规范文件与归档文件冲突、P2b/P4 可能漏更新 AC、AC21 漏 P2b、文档根目录未限制为安全相对路径。

## Issue 1：规范文件与日期归档冲突

**Decision：ACCEPT SONNET FINDING。**

规范文件按阶段要求原位更新；带日期的归档文件遇同名时追加 `_2`、`_3`，不覆盖旧归档。公共落盘文本已改为明确区分两者。

## Issue 2：P2b/P4 的验收标准同步

**Decision：ACCEPT SONNET FINDING。**

P2b 或 P4 若改变 AC，必须同步更新 `ACCEPTANCE.md`；若 AC 未受影响则不改该文件。

## Issue 3：AC21 漏测 P2b

**Decision：ACCEPT SONNET FINDING。**

AC21 明确覆盖 P1、P2、P2b、P3、P4、P5 六步。

## Issue 4：`docsRoot` 输入边界

**Decision：ACCEPT SONNET FINDING。**

只允许相对路径；统一反斜杠为正斜杠、清理 `./` 和末尾斜杠。空值、`.`、绝对路径、盘符路径、`~` 开头路径或包含 `..` 路径段时回退为 `docs` 并提示。页面持久化原始输入，仅生成时使用规范化值。

## 最终基准

完整的 V1.4.1 设计、路径和 AC 见 `../handoff/HANDOFF_latest.md`。该文件取代 V1.4 增量稿，后续 P3/P5 以本地这一版本为准。
