## Issue 1：AC31 未覆盖 Handoff 要求的 4.5:1 对比度

**Decision：ACCEPT。**

**Evidence：** Handoff V1.6 Required Changes 第 6 条要求正文与说明文字对白底对比度 ≥ 4.5:1；`ACCEPTANCE.md` AC31(a)–(e) 只覆盖布局，没有对比度检查对象和判定方法。AC34 是主观美观确认，不能替代这项检查。Sonnet 的判断成立。

**Impact：**
- AC31 增加 (f)：实施后对**最终 CSS 中实际使用的**文字前景/背景组合逐一计算对比度，范围至少包括上表 16 组中仍存在的组合，以及本轮新增或改动的组合（如角色徽章、设置卡片背景）；每组须 ≥ 4.5:1。在实施报告中列出“组合 / 前景 / 背景 / 对比度”表。
- 方法：用 WCAG 2.x 相对亮度公式，基于 CSS 中声明的十六进制颜色静态计算（可用 PowerShell 脚本，脚本不进仓库）。带透明度的颜色按实际叠加后的不透明色计算；无法确定时标 `NOT TESTED` 并说明原因。
- 不在范围内：浏览器默认的 placeholder 颜色、禁用控件（`#status-select` 在 AGENTS 步骤禁用）文字、聚焦轮廓等非文字元素。
- Handoff Required Changes 第 6 条同步写明检查对象和方法；不新增代码范围，代码文件仍只有 `index.html`、`style.css`。
